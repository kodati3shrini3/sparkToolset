# Contributing

Issues and pull requests are welcome.

- Contributions are accepted under the MIT license of this project (see `LICENSE`).
- Keep scripts readable: put a short comment on each line of code that says why it is there.
- Run `bash -n yourScript.sh` before you open a pull request, and say what you tested and on which system.
- Programs must check for the software they need (see `lib/checkRequiredProgramsAvailable.sh`) and must not touch anything outside this toolset.
- Do not commit personal paths, addresses, passwords or tokens.
